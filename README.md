# Lecture2PDF Bot

> **Статус реализации:** доступны модули Арсения — `DocumentService`, `Document`, `Slide`, `FileStorage`,
> `PdfGenerator` и адаптер PDF-рендерера Tesseract. Telegram и обработка изображений
> пока не реализованы. Перечень возможностей ниже описывает целевой проект.
>
> **Начать работу:** [сборка и тесты](docs/build.md) ·
> [контракты модулей и пример интеграции](docs/arseniy-modules.md) ·
> [доска команды в Notion](https://app.notion.com/p/412c344802ad8078b966e1aaaa59653d).

Telegram-бот для преобразования фотографий лекционных слайдов в PDF-документы с распознаваемым текстом.

Пользователь отправляет боту фотографии слайдов, после чего изображения обрабатываются, текст распознаётся с помощью OCR, а результат объединяется в PDF-файл. В итоговом документе текст можно выделять, копировать и искать.

## Основные возможности

- создание новой лекции;
- загрузка нескольких фотографий слайдов;
- хранение фотографий в рамках текущей сессии;
- изменение порядка страниц;
- удаление ненужных страниц;
- обработка изображений перед распознаванием;
- распознавание текста с помощью OCR;
- поддержка русского и английского текста;
- формирование многостраничного PDF;
- добавление текстового слоя в PDF;
- отправка готового PDF через Telegram;
- обработка ошибок пользователя.

## Технологии

- **C++**
- **CMake**
- **Telegram Bot API**
- **OpenCV** — обработка изображений
- **Tesseract OCR** — распознавание текста
- библиотека для генерации PDF
- **GoogleTest / Catch2** — модульное тестирование

# Распределение обязанностей

## Андрей — Telegram-бот и взаимодействие с пользователем

Основная зона ответственности — интерфейс взаимодействия пользователя с системой.

Задачи:

- подключение Telegram Bot API;
- получение сообщений и фотографий;
- обработка команд пользователя;
- реализация команд `/start`, `/new`, `/generate`, `/cancel`;
- передача загруженных фотографий в основную часть программы;
- отображение количества добавленных страниц;
- обработка пользовательских ошибок;
- отправка готового PDF-файла пользователю;
- реализация класса `TelegramBot`;
- реализация `CommandHandler`;
- тестирование логики обработки команд.

Пример компонентов:

```text
TelegramBot
CommandHandler
BotResponse
```

## Егор — обработка изображений и OCR

Основная зона ответственности — подготовка фотографий слайдов и распознавание текста.

Задачи:

- подключение OpenCV;
- загрузка и обработка изображений;
- изменение размера изображения;
- повышение контраста;
- подготовка изображения к OCR;
- при возможности — автоматическое исправление перспективы;
- подключение Tesseract OCR;
- распознавание русского и английского текста;
- получение текста и информации о его расположении на изображении;
- реализация интерфейса `IOcrEngine`;
- реализация `TesseractOcrEngine`;
- реализация `ImageProcessor`;
- обработка ошибок распознавания;
- unit-тестирование обработки изображений и OCR-интерфейса.

Пример компонентов:

```text
ImageProcessor

IOcrEngine
    │
    └── TesseractOcrEngine

OCRResult
```

## Unit-тестирование

В проекте планируется тестировать отдельно основные компоненты.

### Document

- добавление страницы;
- удаление страницы;
- изменение порядка страниц;
- работа с пустым документом;
- получение количества страниц.

### ImageProcessor

- обработка корректного изображения;
- обработка изображения неподдерживаемого формата;
- изменение размера;
- подготовка изображения для OCR.

### OCR

- корректная обработка результата распознавания;
- обработка ошибки OCR;
- использование mock-реализации `IOcrEngine`.

### PdfGenerator

- создание PDF;
- создание многостраничного документа;
- корректный порядок страниц;
- обработка пустого документа.

### Telegram Bot

- обработка команд;
- корректное изменение состояния пользовательской сессии;
- обработка неправильной последовательности действий.
